3. PLATFORM UTAMA: wedding-platform
-----------------------------------

Folder ini adalah aplikasi utama berbasis Next.js.

Route atau halaman yang tersedia:

- /
  Halaman company profile / landing page Occasio.

- /login
  Halaman login demo.

- /client/dashboard
  Dashboard client untuk mengelola undangan, tamu, RSVP, dan konten.

- /owner/dashboard
  Dashboard owner untuk monitoring semua event.

- /wedding/[slug]
  Halaman undangan public berdasarkan slug.
  Contoh:
  /wedding/sheila-yoga


4. STRUKTUR FOLDER PENTING
--------------------------

wedding-platform/package.json
Berisi daftar script dan dependency project.

wedding-platform/src/app
Berisi halaman Next.js App Router.

wedding-platform/src/components
Berisi komponen UI seperti:
- login modal
- auth gate
- dashboard shell
- stat card
- upload Excel tamu
- action modal

wedding-platform/src/lib/demo-data.ts
Berisi data demo untuk event, tamu, ucapan, dan paket.

wedding-platform/src/lib/supabase
Berisi konfigurasi Supabase dan schema database.

wedding-platform/public/templates/sheila-yoga
Berisi asset template undangan yang dipakai oleh halaman /wedding/sheila-yoga.

6. TECH STACK BACK-END
----------------------

Project ini belum punya backend custom seperti Express, NestJS, Laravel, atau Django.

Backend yang disiapkan adalah Supabase.

Supabase dipakai untuk:
- Authentication
- Database PostgreSQL
- Row Level Security
- Data profile
- Data event
- Data tamu
- Data ucapan

Package Supabase:
- @supabase/supabase-js 2.110.0
- @supabase/ssr 0.12.0

Catatan penting:
Saat ini login utama masih memakai mode demo dengan localStorage.
Jadi dashboard bisa dicoba tanpa Supabase.

Supabase sudah disiapkan, tapi belum sepenuhnya menjadi sumber data utama dashboard.


7. DATABASE YANG DISIAPKAN
--------------------------

Schema database ada di:

  Menyimpan user profile dan role.

  Menyimpan ucapan tamu.

Role yang disiapkan:

- owner
- client

Status event:

- active

- archived

- pending
- attending
- declined

15. SETUP SUPABASE CLOUD
------------------------

Jika ingin memakai Supabase beneran:

1. Buka https://supabase.com
2. Buat project baru.
3. Ambil Project URL, anon key, dan service role key.
4. Masukkan ke .env.local.
5. Buka SQL Editor di Supabase.
6. Jalankan isi file:
   wedding-platform/src/lib/supabase/schema.sql
7. Jalankan seed user:

pnpm seed:users
